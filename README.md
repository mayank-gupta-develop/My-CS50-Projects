# 📘 My-CS50-Projects

This repository contains my solutions to **Harvard University’s CS50: Introduction to Computer Science** problem sets and projects.

The work in this repository reflects my learning journey through core computer science concepts, problem-solving techniques, and software development fundamentals.

---

## 🧩 Problem Sets Overview

### 🧩 Problem Set 0 – Scratch
An introduction to computational thinking using Scratch.  
I built a simple interactive program using events, loops, conditionals, and variables to understand core programming logic without writing code.

---

### 🧩 Problem Set 1 – C Basics
My first programs written in C.  
This problem set focused on variables, conditionals, loops, and user input through problems such as `hello`, `mario`, `cash`, and `credit`.

---

### 🧩 Problem Set 2 – Arrays & Cryptography
Worked with strings and arrays in C.  
Implemented basic encryption techniques and practiced string manipulation using ASCII values.

---

### 🧩 Problem Set 3 – Algorithms
Implemented searching and sorting algorithms.  
Learned to compare algorithm efficiency using Big-O notation and worked with linear search, binary search, and sorting techniques.

---

### 🧩 Problem Set 4 – Memory
Explored how memory works in C.  
Used pointers, dynamic memory allocation, structs, and file I/O, including programs that manipulate image data.

---

### 🧩 Problem Set 5 – Data Structures
Implemented core data structures such as linked lists and hash tables.  
Focused on memory management, efficiency, and organizing data effectively.

---

### 🧩 Problem Set 6 – Python
Rewrote earlier C programs using Python.  
Learned Python syntax, dictionaries, lists, and file handling while comparing low-level and high-level programming approaches.

---

### 🧩 Problem Set 7 – SQL
Worked with relational databases using SQL.  
Wrote queries involving SELECT, JOIN, WHERE, and GROUP BY to analyze structured datasets.

---

### 🧩 Problem Set 8 – Web Development
Built basic web pages using HTML, CSS, and JavaScript.  
Focused on client-side logic and interactivity.

---

### 🧩 Problem Set 9 – Flask
Created a dynamic web application using Flask.  
Integrated Python, SQL, and HTML templates while learning routing, sessions, and backend logic.

---

### 🏁 Final Project
Designed and built a complete full-stack application from scratch.  
The final project combines backend development, database usage, authentication, and frontend design, demonstrating a comprehensive understanding of CS50 concepts.
